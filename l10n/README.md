# Localization dictionaries (6 languages)

Every piece of copy the reader can see lives in this folder and nowhere else.
One file per language:

| File | Language |
|---|---|
| `en.tsv` | English (source language) |
| `ru.tsv` | Русский |
| `es.tsv` | Español |
| `pt.tsv` | Português |
| `de.tsv` | Deutsch |
| `fr.tsv` | Français |

## Format

```
key<TAB>text
```

* `#` starts a comment line.
* `\n` is a line break, `\t` a tab, `\\` a backslash.
* `{name}`-style placeholders are filled by `AppStrings.t(lang, key, params)`.
  Every language must keep exactly the same placeholders as English — the
  coverage test (`test/l10n_coverage_test.dart`) enforces it.

## Workflow

```bash
# 1. add/change keys in en.tsv (and optionally translate by hand)
python3 tool/add_l10n.py key "English text" ru "Русский текст"

# 2. fill missing translations (Google, placeholder-safe, resumable)
python3 tool/translate_l10n.py            # all languages
python3 tool/translate_l10n.py --lang es  # one language
python3 tool/translate_l10n.py --force de # retranslate everything

# 3. regenerate the const Dart maps used by the app
python3 tool/gen_l10n_dart.py

# 4. verify
flutter test test/l10n_coverage_test.dart
```

`tool/migrate_content.py`, `tool/migrate_ui.py` and
`tool/migrate_ternaries.py` are the one-off codemods that moved the legacy
hardcoded copy into these files; they are kept for reference and are safe to
re-run only on an un-migrated tree.

## Key namespaces

* `content.*` — card/rune/zodiac/spread/lesson data (`content.tarot.0.name`,
  `content.spread.tarot.three.role.1`, `content.lesson.tarot.three.0`).
* `ui.*` — screen-specific labels generated by the UI codemod.
* `common.*`, `table.*`, `astral.*`, `reading.*`, `profile.*`, `ritual.*`,
  `guide.*`, `intention.*`, `synthesis.*` — shared feature copy.
* `nav.*`, `settings.*`, `onboarding.*`, `pro.*` — navigation and settings.

Card and spread names are keys, not literals: `TarotCard.nameKey`,
`SpreadType.labelKey`, etc. resolve through `AppStrings.current`, which the
settings controller updates before the tree rebuilds.

## Deliberate non-UI exceptions

These strings stay in code because the reader never sees them:

* LLM instructions and JSON-shape prompts in
  `core/services/oracle_synthesis_service.dart` and
  `core/services/vision_scanner_service.dart` (sent to the model, not rendered).
* Debug logs, `assert` messages and thrown exception text.
* Storage keys, JSON field names and the legacy
  `Relationships` / `Career & Path` / `All Readings` normalization map in
  `spread_session_snapshot.dart` (kept so sessions saved before this release
  still load).
* Dev-only `design_system/playground/*`.
